# Birinci Vites marka varlıkları

Onaylanan altı özgün çalışma `assets/brand` altında kaynak kalitesinde saklanır:

- `logo-gradient-source.png`: açık zemin için özgün yatay logo
- `app-icon-source.png`: mağaza ve ana ekran ikonu kaynağı
- `mark-source.png`: şeffaf BV sembolü
- `logo-solid.png`: tek renk yatay logo
- `logo-dark.png`: koyu zeminli yatay logo
- `wordmark.png`: yalnızca yazı biçimi

Uygulamanın kullandığı türevler:

- `logo-horizontal.png`: uygulama başlığı ve GitHub README
- `../icon.png`: iOS ve genel Expo ikonu
- `../android-icon-foreground.png`: Android uyarlanabilir ikon ön planı
- `../android-icon-background.png`: Android uyarlanabilir ikon zemini
- `../android-icon-monochrome.png`: Android temalı ikon
- `../favicon.png`: web faviconu
- `../splash-icon.png`: açılış ekranı sembolü

Türevleri yeniden hazırlamak için `scripts/prepare-brand-assets.ps1` çalıştırılır.
